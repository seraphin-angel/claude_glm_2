## ステータス凡例

| マーク | 意味 |
|--------|------|
| `[ ]` | 未着手 |
| `[~]` | 進行中 |
| `[x]` | 完了 |
| `[!]` | ブロック中（依存関係や課題あり） |

## ファイル構成

```
tasks/
  README.md          # 本ファイル（全体サマリー）
  P0-immediate.md    # P0: 即時対応（10件）
  P1-quarter1.md     # P1: 第1四半期（23件）
  P2-quarter2.md     # P2: 第2四半期（14件）
  P3-quarter3.md     # P3: 第3四半期以降（9件）
```

## 運用ルール

1. タスクに着手したら `[ ]` を `[~]` に変更し、着手日を記入
2. タスク完了時に `[~]` を `[x]` に変更し、完了日を記入
3. ブロック時は `[!]` に変更し、ブロック理由を備考に記入
4. 各タスク完了後、本ファイルの進捗サマリーも更新する
5. 関連 PR / コミットのリンクを備考欄に記録する
