本ページでは、プラン・料金・契約に関するよくあるご質問にお答えします。

## 料金体系

### 課金の仕組み

**月払い**:
- 毎月、月初に1ヶ月分の料金が請求されます。
- 月の途中でユーザーを追加した場合、日割り計算で請求されます。
- 月の途中でユーザーを削除した場合、翌月から適用されます（返金はありません）。

**年払い（10%割引）**:
- 1年分を一括前払いすることで、月払いより10%割引になります。
- 例：スタンダードプランの場合、月払いは8,800円/ユーザー/月ですが、年払いは7,920円/ユーザー/月（1年分: 95,040円/ユーザー）となります。
- 年払い期間中のプラン変更・解約については別途お問い合わせください。

### 無料トライアル

全プランで**14日間の無料トライアル**をご利用いただけます。

- トライアル期間中はプレミアムプランの全機能をご利用いただけます。
- クレジットカードの登録は不要です。
- トライアル終了後、自動的に課金は開始されません。継続利用の場合は、プランを選択してお申し込みください。

### ボリュームディスカウント

50ユーザー以上でご利用の場合、ボリュームディスカウントが適用されます。詳細は営業チームにお問い合わせください。

- 50〜99ユーザー: 5%割引
- 100〜299ユーザー: 10%割引
- 300ユーザー以上: 個別見積もり

## 契約期間と更新

### 契約期間

月払いプランの契約期間は1ヶ月です。毎月自動更新されます。

年払いプランの契約期間は1年です。契約満了日の30日前から更新手続きが可能です。

### 自動更新

月払いプランは毎月1日に自動更新されます。年払いプランは契約満了日に自動更新されます。

自動更新を停止したい場合は、更新日の前日までに「設定」→「プラン・請求」→「自動更新をオフにする」から設定してください。

### プランのアップグレード

プランのアップグレードはいつでも可能です。

1. 「設定」→「プラン・請求」を開きます。
2. 希望するプランの「アップグレード」ボタンをクリックします。
3. 内容を確認して「変更を確定」をクリックします。
4. アップグレードは即時に反映されます。
5. 料金は日割り計算で調整されます。

### プランのダウングレード

プランのダウングレードは現在の契約期間終了時に適用されます。

1. 「設定」→「プラン・請求」を開きます。
2. 希望するプランの「ダウングレード」ボタンをクリックします。
3. ダウングレード後の機能制限について確認します。
4. 「変更を確定」をクリックします。
5. 現在の契約期間終了時（月払いは翌月1日、年払いは更新日）から新しいプランが適用されます。

## 解約手続き

### 解約方法

1. 管理者アカウントでログインします。
2. 「設定」→「プラン・請求」→「解約する」をクリックします。
3. 解約理由を選択します（改善のためにご協力をお願いします）。
4. 解約後のデータの取り扱いについて確認します。
5. 「解約を確定する」をクリックします。
6. 確認メールが送信されます。

解約は即時ではなく、現在の契約期間終了時（月払いは月末、年払いは契約満了日）に適用されます。

### 解約後のデータについて

解約後のデータ保持期間は以下の通りです。

- 解約後30日間: データはそのままアクセス可能（閲覧・エクスポートのみ）
- 30日経過後: 全データが完全に削除されます

解約前に必要なデータをエクスポートしてください。一度削除されたデータは復旧できません。

## 返金ポリシー

### 月払いプランの返金

月払いプランについては、原則として返金は行っておりません。ただし、以下の場合は返金を検討いたします。

- 当社のシステム障害により、SLA（稼働率99.9%）を下回るサービス停止が発生した場合
- 重大な不具合により、有料機能が長期間利用できなかった場合

返金を希望される場合は、サポートチームにお問い合わせください。

### 年払いプランの返金

年払いプランの中途解約については、以下の通りです。

- 契約開始から14日以内: 全額返金
- 14日超〜6ヶ月以内: 残月数分の50%を返金
- 6ヶ月超: 返金なし

### トライアル期間中の課金

無料トライアル期間中は一切の課金は発生しません。トライアル終了後、自動的に課金は開始されません。

## 請求書の確認方法

### 請求書の確認

1. 「設定」→「プラン・請求」→「請求履歴」を開きます。
2. 確認したい月の請求書をクリックします。
3. 請求書の詳細（請求金額・内訳・支払い方法・ステータス）が表示されます。
4. 「PDFをダウンロード」ボタンで請求書をPDF形式でダウンロードできます。

### 請求書の自動送信

請求書は毎月、登録されたメールアドレスに自動的に送信されます。送信先を変更するには以下の手順で行ってください。

1. 「設定」→「プラン・請求」→「請求先情報」を開きます。
2. 「請求書送付先メールアドレス」を変更します。
3. 複数のアドレスを登録することもできます（カンマ区切り）。
4. 「保存」をクリックして変更を反映します。

### 支払い方法の変更

対応している支払い方法は以下の通りです。

- クレジットカード（Visa・Mastercard・American Express・JCB）
- 銀行振込（スタンダード・プレミアムのみ、要申請）
- 請求書払い（プレミアムのみ、要申請）

支払い方法を変更するには「設定」→「プラン・請求」→「支払い方法」から変更してください。

クレジットカードの有効期限切れや決済失敗の場合は、メールでお知らせします。7日以内に支払い方法を更新しないと、サービスが一時停止されます。

### 領収書の発行

領収書が必要な場合は、請求書詳細ページの「領収書を発行」ボタンをクリックしてください。領収書はPDF形式でダウンロードできます。

会社名・住所・宛名を変更したい場合は「請求先情報」から変更してください。変更後の情報は次回以降の請求書・領収書に反映されます。

## よくあるご質問（料金・契約）

**Q: 無料プランはありますか？**
A: 無料プランのご用意はありませんが、14日間の無料トライアルをご利用いただけます。トライアル期間中はプレミアムプランの全機能をお試しいただけます。

**Q: 途中でユーザーを追加・削除できますか？**
A: はい、いつでも可能です。ユーザーを追加した場合は日割り計算で追加料金が発生します。ユーザーを削除した場合は翌月から料金が変更されます。

**Q: 非営利団体や教育機関向けの割引はありますか？**
A: 非営利団体・教育機関・スタートアップ向けの特別プログラムをご用意しています。詳細は営業チーム（sales@example.com）にお問い合わせください。

**Q: 複数の組織（ワークスペース）を持つことはできますか？**
A: はい、可能です。ただし、ワークスペースごとに個別に料金が発生します。

**Q: 請求書払い（後払い）に対応していますか？**
A: プレミアムプランでは請求書払いに対応しています。ご希望の場合は営業チームにお問い合わせください。

**Q: 海外からの利用は可能ですか？**
A: はい、世界中からご利用いただけます。料金は日本円での請求となります。

**Q: データの所在地（データセンターの場所）はどこですか？**
A: 日本国内のデータセンター（東京・大阪）を使用しています。プレミアムプランではデータの所在地を指定することも可能です。

**Q: 契約前に見積書を取得できますか？**
A: はい、営業チーム（sales@example.com）にご要望をお伝えいただければ、見積書を発行いたします。
