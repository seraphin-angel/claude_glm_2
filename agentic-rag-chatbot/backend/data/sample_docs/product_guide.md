# 製品操作ガイド

本ガイドでは、製品A・製品B・製品Cの基本的な操作方法について説明します。
初期設定からデイリーユースまで、ステップごとに詳しく解説しています。

## 製品A 操作ガイド

製品Aは、中小企業向けの業務管理ツールです。シンプルな操作性と豊富な機能を兼ね備えています。

### 製品Aの初期設定

製品Aを初めて利用する場合は、以下の手順で初期設定を行ってください。

1. 公式サイト（https://product-a.example.com）にアクセスし、「無料トライアルを開始」ボタンをクリックします。
2. 会社名・メールアドレス・電話番号を入力し、利用規約に同意してアカウントを作成します。
3. 登録したメールアドレスに確認メールが届きますので、メール内のリンクをクリックして認証を完了します。
4. 初回ログイン後、セットアップウィザードが起動します。画面の指示に従って、組織情報・タイムゾーン・言語設定を行います。
5. 管理者アカウントのパスワードを設定します。パスワードは英大文字・英小文字・数字・記号を含む12文字以上を推奨します。
6. チームメンバーを招待するには、「設定」→「ユーザー管理」→「招待を送る」から招待メールを送信します。

### 製品Aへのログイン方法

1. 製品Aのログインページ（https://app.product-a.example.com/login）にアクセスします。
2. 登録済みのメールアドレスとパスワードを入力します。
3. 「ログイン」ボタンをクリックします。
4. 二要素認証（2FA）が有効な場合は、認証アプリまたはSMSに届いたコードを入力します。
5. ログインに成功すると、ダッシュボードが表示されます。

ログインできない場合は、「パスワードをお忘れですか？」リンクからパスワードのリセットを行ってください。

### 製品Aのダッシュボード

ダッシュボードは製品Aのメイン画面です。以下のウィジェットが表示されます。

- **タスクサマリー**: 本日のタスク一覧と完了状況
- **チームアクティビティ**: チームメンバーの最近の操作履歴
- **プロジェクト進捗**: 進行中プロジェクトの達成率
- **通知センター**: 未読の通知とアラート

ダッシュボードのレイアウトはドラッグ＆ドロップでカスタマイズできます。ウィジェットを追加・削除するには、右上の「ダッシュボードを編集」ボタンをクリックしてください。

### 製品Aのレポート生成

レポートを生成する手順は以下の通りです。

1. 左側のナビゲーションメニューから「レポート」をクリックします。
2. 「新規レポート作成」ボタンをクリックします。
3. レポートの種類を選択します（売上レポート・タスクレポート・チームパフォーマンスレポートなど）。
4. 期間・対象プロジェクト・対象メンバーなどのフィルター条件を設定します。
5. 「レポートを生成」ボタンをクリックします。
6. 生成されたレポートはPDF・CSV・Excelの各形式でダウンロードできます。

定期レポートを自動送信するには、「スケジュール設定」から送信頻度（日次・週次・月次）と送信先メールアドレスを設定してください。

### 製品Aのアカウント設定

#### パスワードの変更

1. 右上のアカウントアイコンをクリックし、「アカウント設定」を選択します。
2. 「セキュリティ」タブをクリックします。
3. 現在のパスワード・新しいパスワード・新しいパスワード（確認）を入力します。
4. 「パスワードを変更する」ボタンをクリックして保存します。

パスワードは定期的に変更することを推奨します。他のサービスと同じパスワードは使用しないでください。

#### 通知設定

1. 「アカウント設定」→「通知」タブを開きます。
2. メール通知・プッシュ通知・社内通知の各項目をオン/オフできます。
3. 通知の頻度（リアルタイム・1時間おき・1日1回）を選択できます。
4. 特定のプロジェクトやタスクに関する通知のみ受け取るフィルター設定も可能です。
5. 「設定を保存」ボタンで変更を反映させます。

#### 言語設定

製品Aは以下の言語に対応しています。

- 日本語
- 英語（English）
- 中国語（简体中文）
- 韓国語（한국어）
- フランス語（Français）
- ドイツ語（Deutsch）

言語を変更するには、「アカウント設定」→「一般」→「言語」から希望の言語を選択し、「保存」をクリックします。変更は次回ログイン時に反映されます。

### 製品Aのデータエクスポート

データをエクスポートする手順は以下の通りです。

1. 「設定」→「データ管理」→「エクスポート」を選択します。
2. エクスポートしたいデータの種類（タスク・プロジェクト・メンバー情報・レポートなど）を選択します。
3. エクスポート形式（CSV・JSON・XML）を選択します。
4. 「エクスポートを開始」ボタンをクリックします。
5. 処理が完了すると、ダウンロードリンクをメールでお知らせします。
6. リンクをクリックしてファイルをダウンロードしてください（リンクの有効期限は24時間です）。

### 製品Aのデータインポート

外部データをインポートするには以下の手順に従います。

1. 「設定」→「データ管理」→「インポート」を選択します。
2. インポートするデータの種類を選択します。
3. インポートファイル（CSV形式推奨）を選択し、アップロードします。
4. フィールドマッピング画面で、ファイルの列とシステムのフィールドを対応付けます。
5. 「プレビュー」ボタンでインポート内容を確認します。
6. 問題がなければ「インポートを実行」をクリックします。
7. インポート結果（成功件数・エラー件数）がレポートとして表示されます。

インポート前に必ずデータをバックアップしてください。インポートは元に戻せない操作です。

## 製品B 操作ガイド

製品Bは、エンタープライズ向けのCRMシステムです。顧客管理・商談管理・マーケティング自動化を一元化します。

### 製品Bの初期設定

1. 契約完了後、管理者メールアドレスにアクセス情報が送付されます。
2. メール内のURLからログインし、初期パスワードを変更します。
3. 「組織設定」から会社情報（社名・住所・電話番号・ロゴ）を設定します。
4. 「ユーザー・権限管理」で部署・役職・アクセス権限を設定します。
5. CRMデータ（顧客情報・商談情報）のインポートを行います。
6. メール連携（Gmail・Outlookなど）を設定します。

### 製品Bへのログイン方法

1. 管理者から通知されたログインURLにアクセスします（通常は https://[会社名].product-b.example.com）。
2. ユーザーIDとパスワードを入力してログインします。
3. シングルサインオン（SSO）が設定されている場合は、会社のSSOポータル経由でログインします。
4. 初回ログイン時はパスワード変更と2FA設定が必要です。

### 製品Bのダッシュボード

製品BのダッシュボードにはSalesチームとMarketingチームで異なるビューが表示されます。

**Salesダッシュボード**:
- 本日の商談・案件一覧
- 月間売上目標と達成状況
- パイプラインの状況（フェーズ別件数・金額）
- フォローアップが必要な顧客リスト

**Marketingダッシュボード**:
- キャンペーンのパフォーマンス指標
- リード獲得数と転換率
- メール開封率・クリック率
- A/Bテストの結果

### 製品Bのレポート生成

1. トップメニューから「分析・レポート」をクリックします。
2. テンプレートから選択するか、カスタムレポートを作成します。
3. 集計軸（期間・担当者・地域・製品カテゴリ）と指標（件数・金額・転換率）を設定します。
4. グラフ種類（折れ線グラフ・棒グラフ・円グラフ・ヒートマップ）を選択します。
5. 「レポートを実行」ボタンでデータを集計します。
6. 「共有」ボタンで特定のメンバーやグループにレポートを共有できます。

### 製品Bのアカウント設定

#### パスワードの変更

1. 画面右上のユーザーアイコンをクリックします。
2. 「個人設定」→「セキュリティ設定」を選択します。
3. 現在のパスワードを入力し、新しいパスワードを2回入力します。
4. 「更新」ボタンをクリックして保存します。

#### 通知設定

1. 「個人設定」→「通知設定」を開きます。
2. 担当案件の更新・メンションされた場合・タスクの期限などの通知項目を設定します。
3. 通知チャンネル（メール・Slack・LINE WORKS・チャット）を選択します。

#### 言語・タイムゾーン設定

1. 「個人設定」→「表示設定」を開きます。
2. 言語・タイムゾーン・日付フォーマット・通貨表示形式を選択します。
3. 「保存」をクリックして変更を適用します。

### 製品Bのデータエクスポート/インポート

エクスポート機能は「管理者設定」→「データ管理」から行います。顧客データ・商談データ・活動履歴を一括でエクスポートできます。

インポートは専用のインポートウィザードを使用します。CSVテンプレートをダウンロードし、必要なデータを入力後にアップロードしてください。

## 製品C 操作ガイド

製品Cは、プロジェクト管理に特化したコラボレーションツールです。アジャイル開発チームから大規模プロジェクトまで対応します。

### 製品Cの初期設定

1. https://product-c.example.com にアクセスし、アカウントを作成します。
2. プランを選択します（フリー・スターター・ビジネス・エンタープライズ）。
3. ワークスペース名を設定します（通常は会社名や部署名を使用します）。
4. チームメンバーをメールで招待するか、招待リンクを共有します。
5. 最初のプロジェクトを作成します。プロジェクトテンプレートから選択するか、ゼロから作成できます。
6. プロジェクトのワークフロー（かんばん・スプリント・ガントチャート）を選択します。

### 製品Cへのログイン方法

1. https://app.product-c.example.com にアクセスします。
2. メールアドレスとパスワードを入力してログインします。
3. Googleアカウント・GitHubアカウントでのソーシャルログインも利用可能です。
4. SAML SSOを利用する企業は、管理者が発行したSSOポータルURLからログインします。

### 製品Cのダッシュボード

ダッシュボードには以下の情報が表示されます。

- **マイタスク**: 自分に割り当てられたタスクの一覧（期限・優先度順）
- **最近のアクティビティ**: チームメンバーの最新の操作履歴
- **プロジェクト一覧**: 参加しているプロジェクトと進捗状況
- **お気に入り**: よく使うプロジェクトやタスクをピン留めして素早くアクセス

### 製品Cのレポート生成

製品Cでは以下のレポートが利用できます。

1. **バーンダウンチャート**: スプリントの進捗を可視化
2. **ベロシティレポート**: スプリントごとの完了ストーリーポイントの推移
3. **チームキャパシティレポート**: メンバーごとの作業負荷と空き状況
4. **累積フローダイアグラム**: ワークフローの各ステージにある作業量の推移

レポートを生成するには、プロジェクト画面の「レポート」タブをクリックし、表示したいレポートを選択します。

### 製品Cのアカウント設定

#### パスワードの変更

1. 右上のアバターをクリックし、「プロフィール設定」を選択します。
2. 「パスワード変更」セクションで現在のパスワードと新しいパスワードを入力します。
3. 「変更を保存」ボタンをクリックします。

#### 通知設定

製品Cでは細かい通知設定が可能です。

1. 「プロフィール設定」→「通知設定」を開きます。
2. プロジェクト単位・ボード単位・タスク単位で通知を設定できます。
3. @メンション・タスクの担当変更・コメント追加・ステータス変更などの通知項目を設定します。
4. メール通知の他、Slack・Microsoft Teams・Webhookへの通知も設定できます。

#### 言語設定

1. 「プロフィール設定」→「言語」から使用言語を選択します。
2. 現在対応言語は日本語・英語・スペイン語・ポルトガル語・フランス語・ドイツ語です。
3. UIの言語が変更されます（プロジェクトのタイトルや説明文は変更されません）。

### 製品Cのデータエクスポート

1. 「ワークスペース設定」→「データのエクスポート」を選択します。
2. エクスポートするデータの種類とフォーマットを選択します。
   - タスク一覧: CSV形式
   - プロジェクト全体: JSON形式
   - ガントチャート: CSV/Excel形式
   - タイムシート: CSV形式
3. エクスポートを実行すると、メールにダウンロードリンクが送信されます。

### 製品Cのデータインポート

外部ツールからのデータ移行に対応しています。

対応インポート元:
- Jira
- Trello
- Asana
- Basecamp
- 汎用CSV（カスタムフィールドマッピング対応）

インポートは「ワークスペース設定」→「データのインポート」から実施します。インポート中はシステムの応答が遅くなる場合があります。大量データのインポートは業務時間外に行うことを推奨します。
