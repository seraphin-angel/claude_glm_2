# 障害・トラブル対応ガイド

このガイドでは、製品をご利用中に発生する可能性のある問題と、その対処法を説明します。
問題が解決しない場合は、サポートチームにお問い合わせください。

## ログインできない場合

ログインに失敗する原因と対処法を説明します。

### パスワードを忘れた場合

1. ログインページで「パスワードをお忘れですか？」リンクをクリックします。
2. 登録済みのメールアドレスを入力し、「リセットメールを送信」をクリックします。
3. 数分以内にパスワードリセット用のメールが届きます。
4. メール内のリンクをクリックし、新しいパスワードを設定します。
5. リンクの有効期限は1時間です。期限が切れた場合は再度リセット手続きを行ってください。

メールが届かない場合は、迷惑メールフォルダをご確認ください。それでも届かない場合はサポートへお問い合わせください。

### アカウントがロックされた場合

パスワードを5回連続で間違えるとアカウントがロックされます。

ロック解除の方法:
1. 30分間待つと自動的にロックが解除されます。
2. または、管理者に連絡してロック解除を依頼してください。
3. 管理者は「ユーザー管理」→「対象ユーザー」→「アカウントのロック解除」から操作できます。

### 二要素認証（2FA）が使えない場合

認証アプリが使えない場合:
1. ログイン画面で「別の方法でログイン」をクリックします。
2. バックアップコードを使用します（初回2FA設定時に発行されたコード）。
3. バックアップコードも使えない場合は、管理者に2FA無効化を依頼してください。

管理者が2FAを無効化する手順:
1. 「ユーザー管理」→「対象ユーザー」→「セキュリティ設定」を開きます。
2. 「二要素認証を無効化」ボタンをクリックします。
3. ユーザーが再ログインして新しい2FAを設定します。

### SSO（シングルサインオン）でログインできない場合

1. 会社のネットワーク（VPNを含む）に接続されているか確認します。
2. 使用しているブラウザのキャッシュとCookieをクリアして再試行します。
3. SSOの設定が正しいか管理者に確認を依頼します。
4. システム管理者はSAML設定（メタデータURL・証明書・属性マッピング）を再確認してください。

## 画面が表示されない・エラーが出る場合

### ページが白くなる（ホワイトスクリーン）

1. ブラウザを最新バージョンに更新してください。対応ブラウザはChrome・Firefox・Edge・Safariです。
2. ブラウザのキャッシュをクリアします（Ctrl+Shift+Delete またはCommand+Shift+Delete）。
3. シークレット（プライベート）モードで開いてみてください。
4. 拡張機能（アドブロッカーなど）を一時的に無効化して再試行してください。
5. 別のブラウザで試してください。
6. 問題が解決しない場合は、ブラウザのコンソールに表示されているエラーメッセージをサポートにお送りください。

### 特定の機能が動作しない

1. ページを強制リロードしてください（Ctrl+Shift+R またはCommand+Shift+R）。
2. 別のデバイス・ブラウザで同じ問題が発生するか確認します。
3. システムメンテナンスの通知が出ていないか、ステータスページ（status.example.com）を確認します。
4. 管理者は当該機能の権限設定が正しいか確認してください。

### エラーメッセージが表示される

エラーメッセージが表示された場合は、エラーコードと表示内容を記録してサポートにご連絡ください。
主なエラーコードについては「よくあるエラーコード一覧」セクションを参照してください。

## データが同期されない場合

### リアルタイム更新が反映されない

1. インターネット接続を確認します。他のサービスにアクセスできるか確認してください。
2. ページをリロードして最新データを取得します。
3. WebSocket接続が必要なため、プロキシやファイアウォールがWebSocketをブロックしていないか確認します。

IT管理者向けの確認事項:
- WebSocket（wss://）の通信が許可されているか
- プロキシ設定でWebSocketのアップグレードリクエストが通過できるか
- ファイアウォールのポート443（HTTPS/WSS）が開放されているか

### 外部連携のデータが同期されない（CRM・会計ソフトなど）

1. 連携設定が有効になっているか確認します（「設定」→「連携管理」）。
2. 連携サービスのAPIキーやアクセストークンが有効期限内であるか確認します。
3. 連携サービスの認可を再実行します（「連携を再接続」ボタン）。
4. 連携ログを確認して、エラーの詳細を把握します（「設定」→「連携管理」→「ログ」）。

### ファイルのアップロードが失敗する

1. アップロードするファイルのサイズ制限を確認します（プランによって異なりますが、通常100MB以内）。
2. 対応しているファイル形式か確認します。
3. ブラウザのキャッシュをクリアして再試行します。
4. 別のブラウザやデバイスで試してください。
5. 問題が続く場合は、ファイル名に特殊文字や日本語が含まれていないか確認し、英数字のみのファイル名に変更して試してください。

## パフォーマンスが遅い場合

### 画面の表示が遅い

1. インターネット回線速度を確認します。推奨速度は下り10Mbps以上です。
2. 同時に多くのタブを開いている場合は、不要なタブを閉じてください。
3. ブラウザの拡張機能（特にアドブロッカー・セキュリティソフト連携）を一時的に無効化します。
4. ブラウザのキャッシュをクリアします。
5. PCを再起動してみてください。

### データの読み込みが遅い

大量データを扱う場合のパフォーマンス改善方法:
1. 表示件数を減らします（例: 1ページあたり20件に設定）。
2. 検索フィルターを活用して表示データを絞り込みます。
3. 不要なカラムの表示をオフにします。
4. エクスポートして外部ツールで分析することも検討してください。

## API連携のエラー

### APIキーに関するエラー

**401 Unauthorized エラー**:
- APIキーが正しいか確認してください。
- APIキーの有効期限が切れていないか確認してください。
- APIキーに必要な権限が付与されているか確認してください。

APIキーの再発行手順:
1. 「設定」→「API管理」→「APIキー」を開きます。
2. 既存のキーを無効化します。
3. 「新しいAPIキーを生成」をクリックします。
4. 生成されたキーを安全な場所に保存します（表示されるのは一度だけです）。
5. 連携先のシステムにて新しいAPIキーを設定します。

### APIレート制限に関するエラー

**429 Too Many Requests エラー**:
- APIのレート制限（1分間あたりのリクエスト数）を超えています。
- リクエストの頻度を下げてください。
- レート制限はプランによって異なります（ベーシック: 60回/分、スタンダード: 300回/分、プレミアム: 1000回/分）。
- 指数バックオフを実装して、エラー時に自動的にリトライ間隔を延ばすことを推奨します。

### Webhook受信に関するエラー

Webhookが届かない場合:
1. WebhookのURLが正しく設定されているか確認します。
2. 受信サーバーがHTTPS（TLS 1.2以上）に対応しているか確認します。
3. サーバーのファイアウォールで、当サービスのIPアドレスからのアクセスが許可されているか確認します。
4. Webhookのシークレットキーで署名の検証を行っているか確認します。
5. 受信サーバーが200 OKを3秒以内に返しているか確認します（タイムアウトするとリトライが発生します）。

## よくあるエラーコード一覧

本システムで発生する代表的なエラーコードとその対処法を説明します。

### E001: 認証エラー

**内容**: ログイン情報が正しくない、またはセッションが期限切れです。
**対処法**:
- メールアドレスとパスワードを再確認してください。
- ブラウザのCookieをクリアして再度ログインしてください。
- セッションが切れた場合は再ログインが必要です。

### E002: 権限エラー

**内容**: 操作に必要な権限がありません。
**対処法**:
- 管理者に権限の付与を依頼してください。
- 自分のロール・権限設定を確認してください（「アカウント設定」→「権限情報」）。

### E003: リソースが見つからない

**内容**: 指定したデータ・ページが存在しません。
**対処法**:
- URLが正しいか確認してください。
- データが削除されていないか確認してください。
- ブラウザの戻るボタンで前の画面に戻ってください。

### E004: バリデーションエラー

**内容**: 入力値が要件を満たしていません。
**対処法**:
- 各フィールドのエラーメッセージを確認し、適切な値を入力してください。
- 必須項目が未入力でないか確認してください。
- 文字数制限・形式（メールアドレス・電話番号・日付形式など）を確認してください。

### E005: 重複エラー

**内容**: 同じ値がすでに登録されています。
**対処法**:
- メールアドレスや識別子が他のレコードと重複していないか確認してください。
- 既存のレコードを編集するか、別の値を使用してください。

### E006: ファイルサイズエラー

**内容**: アップロードしたファイルがサイズ制限を超えています。
**対処法**:
- ファイルサイズを確認してください（上限は100MB）。
- 大きなファイルは圧縮するか、分割してアップロードしてください。

### E007: タイムアウトエラー

**内容**: 処理がタイムアウトしました。
**対処法**:
- インターネット接続を確認してください。
- 処理するデータ量が多い場合は、データを分割して実行してください。
- しばらく時間をおいて再試行してください。

### E008: サービス障害

**内容**: サーバー側で障害が発生しています。
**対処法**:
- ステータスページ（status.example.com）でサービスの稼働状況を確認してください。
- 復旧まで時間をおいてから再試行してください。
- 緊急の場合はサポートにお問い合わせください。

### E009: データ整合性エラー

**内容**: データの整合性に問題があります。
**対処法**:
- 入力データの形式や値の範囲を確認してください。
- 関連データが正しく設定されているか確認してください。
- 問題が解決しない場合はサポートにお問い合わせください。

### E010: API制限エラー

**内容**: APIの利用制限に達しました。
**対処法**:
- APIリクエストの頻度を下げてください。
- より上位のプランへのアップグレードを検討してください。
- バッチ処理など、リクエスト数を最小化する実装を検討してください。

## サポートへの問い合わせ方法

問題が解決しない場合は、以下の方法でサポートにご連絡ください。

- **チャットサポート**: 画面右下のチャットアイコンから（平日9:00〜18:00）
- **メールサポート**: support@example.com（24時間受付、通常1営業日以内に返答）
- **電話サポート**: 0120-XXX-XXX（平日9:00〜18:00）

問い合わせの際は、以下の情報をお伝えいただくとスムーズに対応できます。

1. エラーコードまたはエラーメッセージ（スクリーンショット推奨）
2. 問題が発生した日時
3. 使用しているブラウザとバージョン
4. 再現手順（どの操作をした時に問題が発生したか）
5. アカウントのメールアドレス
