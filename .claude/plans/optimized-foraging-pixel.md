# Codexスキル セキュリティ改善プラン

## コンテキスト

`.claude/skills/codex/SKILL.md` のセキュリティ評価を実施した結果、データ漏洩リスクが判明。ユーザーの選択に基づき、警告機能を追加して継続使用する。

**問題点**: プロジェクト全体をOpenAIに送信するため、`.env`ファイル等の機密情報が漏洩する可能性がある。

---

## 実装プラン

### 変更対象ファイル

`/workspace/.claude/skills/codex/SKILL.md`

### 変更内容

1. **セキュリティ警告セクションを追加**
   - 機密情報の扱いに関する注意喚起
   - `.env`等のファイルが含まれる場合の警告

2. **安全な使用ガイドライン追加**
   - 実行前チェックリスト
   - 除外すべきファイルパターンの明記

3. **代替手段の案内**
   - Claude Code標準の`code-reviewer`エージェントの紹介

---

## 追加する内容

```markdown
## ⚠️ セキュリティ警告

**このスキルはプロジェクト全体をOpenAIのサーバーに送信します。**

### 実行前チェックリスト

- [ ] `.env`、`.env.local`、`.env.*` ファイルが含まれていないか確認
- [ ] `credentials.*`、`secrets.*` ファイルが含まれていないか確認
- [ ] API鍵、パスワード、トークンがコード内にハードコードされていないか確認
- [ ] 本番環境の設定ファイルが含まれていないか確認

### 機密ファイルの除外方法

プロジェクトに機密ファイルがある場合は、一時ディレクトリにコピーして除外してから実行：

\`\`\`bash
# 安全な実行手順
mkdir -p /tmp/codex-safe
cp -r src/ /tmp/codex-safe/  # ソースコードのみコピー
# .env等はコピーしない
codex exec --full-auto --sandbox read-only --cd /tmp/codex-safe "..."
\`\`\`

### 代替手段

機密情報を含むプロジェクトでは、Claude Code標準のエージェントを使用：

- **code-reviewer**: コードレビュー（外部送信なし）
- **security-reviewer**: セキュリティ監査（外部送信なし）
```

---

## 検証方法

1. 更新後のSKILL.mdを読み込んで内容確認
2. セキュリティ警告が目立つ位置にあることを確認
3. チェックリストが実用的であることを確認
