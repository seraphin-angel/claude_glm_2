# Plan: ルート `.gitignore` の作成

## Context

ワークスペースにはルートレベルの `.gitignore` が存在せず、3つのプロジェクト（`agentic-rag-chatbot`, `sample3`, `solar-system-3d`）と多数のツール設定ディレクトリが混在している。`sample3` と `agentic-rag-chatbot` には個別の `.gitignore` があるが、`solar-system-3d` にはない。生成ファイル・依存関係ディレクトリが約2GBあり、適切に無視する必要がある。

## ユーザー判断事項（確認済み）

- `.claude/` → **全てトラック**（`.gitignore` に追加しない）
- ロックファイル → **トラックする**（`.gitignore` に追加しない）
- `.serena/` → **全て無視**

### 設計判断の根拠

| パターン | 理由 |
|---------|------|
| `node_modules/` | 3プロジェクト合計 1.2GB、`npm install` で復元可能 |
| `.venv/` / `venv/` | Python仮想環境 431MB、`uv sync` で復元可能 |
| `dist/` / `.next/` / `.swc/` | ビルド成果物、ビルドコマンドで再生成可能 |
| `__pycache__/` / `*.py[cod]` | Python バイトコードキャッシュ |
| `coverage/` / `test-results/` | テスト実行時に再生成される |
| `.env` / `.env.local` | シークレット含有の可能性、`.env.example` は除外しない |
| `.serena/` | ユーザー判断により全て無視 |
| `.agents/` | `.claude/agents/` と重複する冗長ディレクトリ |
| `.playwright/` | ローカルCLI設定のみ、共有不要 |
| `.claude/` | **含めない**（ユーザー判断により全てトラック） |
| ロックファイル | **含めない**（再現可能ビルドのためトラック） |

### サブプロジェクトの `.gitignore` との関係

- `agentic-rag-chatbot/.gitignore` — 既存で十分。ルートと一部重複するが問題なし（Git は両方評価）
- `sample3/.gitignore` — 既存で十分。`/` プレフィックス付きパターンはプロジェクト内のみに適用
- `solar-system-3d/` — 個別の `.gitignore` は不要。ルートのパターンでカバー

## 対象ファイル

- **新規作成**: `/workspace/.gitignore`

## 検証方法

1. `git status` で無視対象が正しく除外されていることを確認
2. `.claude/` 配下のファイルが引き続きトラック可能であることを確認
3. `.env.example` ファイルがトラック対象のままであることを確認
4. ロックファイル（`package-lock.json`, `uv.lock`）がトラック対象のままであることを確認
