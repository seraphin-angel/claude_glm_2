# 桃太郎：鬼退戦（Oni Taiji）アプリケーション実装計画

## コンテキスト

日本の昔話「桃太郎」をテーマにした、ターン制バトルRPGゲームを作成します。桃太郎とその仲間たち（さる、いぬ、きじ）が鬼ヶ島で鬼たちと戦うインタラクティブなアプリケーションを `example/` フォルダに実装します。

## アプリケーションタイプ

**ターン制バトルRPG**
- プレイヤーは桃太郎パーティの行動を選択
- 4人の仲間（桃太郎、さる、いぬ、きじ）がそれぞれ固有のスキルを持つ
- 鬼の敵との戦闘でターン制コマンドバトル

## エージェントチーム構成

桃太郎の仲間にちなんだエージェントチームを編成：

| コンパニオン | エージェント役割 | 責任範囲 |
|-------------|-----------------|----------|
| **桃太郎（リーダー）** | オーケストレーター | 全エージェントの調整、ゲームフローの管理、タスクの委任 |
| **きじ（Kiji）** | アーキテクト | システム設計、コード構成、技術的決定 |
| **さる（Saru）** | UI実装エージェント | コンポーネント開発、ユーザーインタラクション、アニメーション |
| **いぬ（Inu）** | テスト/QAエージェント | テストカバレッジ、バグ検出、品質保証 |

## 技術スタック

- **フロントエンド**: Next.js 15 + React 19
- **言語**: TypeScript 5.6
- **スタイリング**: Tailwind CSS
- **状態管理**: Zustand
- **テスト**: Vitest（単体・統合）+ Playwright（E2E）
- **開発ツール**: ESLint, Prettier

## 実装フェーズ

### フェーズ1：プロジェクト基盤（きじ/アーキテクト）

1. Next.js プロジェクトの初期化（TypeScript + Tailwind）
2. フォルダ構造の作成
3. コア型定義の作成：
   - `types/game.ts` - GameState, GamePhase
   - `types/character.ts` - Character, Stats, Skill
   - `types/battle.ts` - BattleAction, TurnOrder, BattleResult
4. ゲーム定数の定義（キャラクター stats、敵設定）

### フェーズ2：ゲームエンジン（さる実装、いぬテスト）

TDDアプローチで実装：
1. `lib/game/engine.ts` - 状態管理
2. `lib/game/combat.ts` - ダメージ計算
3. `lib/entities/` - キャラクター/敵クラス
4. `lib/game/ai.ts` - 敵AIロジック
5. 各モジュールの単体テスト（80%+ カバレッジ）

### フェーズ3：UIコンポーネント（さる）

1. ベースUIコンポーネント（Button, Card, ProgressBar）
2. ゲームコンポーネント：
   - GameBoard - メインゲームコンテナ
   - PartyPanel - パーティ表示
   - EnemyPanel - 敵表示
   - ActionMenu - コマンド選択
   - BattleLog - 戦闘履歴
3. カスタムフック（useGameState, useBattle）

### フェーズ4：統合とページ（桃太郎オーケストレーター）

1. `app/page.tsx` - ランディング/イントロ
2. `app/game/page.tsx` - メインゲームページ
3. ゲームフローの接続
4. E2Eテスト（Playwright）

### フェーズ5：ポリッシュと最終確認

1. CSSアニメーション
2. ダメージ数値ポップアップ
3. 勝利/敗北画面
4. コードレビューと品質確認
